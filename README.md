# investment-operations-dashboard
Executive dashboard for institutional real estate investment operations, asset management, compliance, and investor reporting.

## Features

- Executive KPI monitoring
- Acquisitions pipeline tracking
- Asset management metrics
- Investor reporting
- Lender compliance monitoring
- Risk management dashboard
- EOS-inspired accountability system

## Technologies

- HTML
- CSS
- JavaScript
- Chart.js
- Tailwind CSS

## Live Demo

## Purpose

This project demonstrates how operational, compliance, investor reporting, and risk management data can be consolidated into a single executive dashboard for institutional real estate investment firms.
